1. Стандартное значение гравитации: -9,81; У игрока значение Gravity Scale = 0, на него гравитация не действует
Масса игрока: 10
У остальных физических объектов Rigidbody 2D с Body Type = Kinematic, либо Rigidbody 2D вообще отсутствует.
Все физические объекты имеют физический материал по умолчанию (Physics Material 2D), т.е. трение и упругость по умолчанию, объекты не отскакивают и не скользят специально.

2. Префабы препятствия: Door (Door3D), DoorKey (DoorKey3D)
Физическая граница уровня: Wall (Wall3D)
Префабы, с помощью которых игрок проходит дальше по уровню: Key, Lever
Префабов, наносящих урон и дающих бонусов нет

3. В сценах нет объектов Canvas, в Assets нет префабов и скриптов UI.
4. На сложность и поведение игры через Inspector влияют следующие параметры:
CharacterTopDown: Mass (масса игрока), размеры коллайдера, Move_accel (разгон), Move_deccel (торможение), Move_max (скорость игрока)
Door/DoorKey: Is Trigger, Nb_switches_required (сколько ключей/рычагов нужно для открытия), Open_speed (скорость открытия двери), Close_speed (скорость закрытия двери), Max_move (насколько широко открывается дверь), Key_can_open (можно ли открыть дверь ключом), Key_index (индекс ключа, открывающего дверь)
Key: Key_index, размеры коллайдера
Lever: Is Trigger, размеры коллайдера
Wall: размеры коллайдера
