\##Изменения Джуниора



\- Добавлена новая комната, вход в которую открывается с помощью рычага - чтобы добавить дополнительно игровое взаимодействие и переместить туда ключ.

\- Ключ перемещен в новую комнату - чтобы у игрока была мотивация к исследованию уровня.

\- Добавлен лабиринт в качестве последней комнаты - чтобы усложнить финальную часть уровня и добавить новый тип препятствия. 

\- Скорость игрока увеличена с 3 до 5 - чтобы сделать перемещение по карте более динамичным.
