Описание:
Проект представляет собой прототип TopDown на основе шаблона TopDownDemo от IndieMarc, модифицированный в рамках лабораторной работы по работе с Git и Unity. Основная цель - отработка навыков разрешения конфликтов слияния в сценах Unity.

Требования:
Unity Hub (Unity Version: 2020.3.49f1)
Git

Запуск:
1. Клонируйте репозиторий: «git clone https://github.com/kweers/UraRiba_project1.git
2. Откройте проект через Unity Hub.
3. Откройте сцену «Assets/IndieMarc/TopDownDemo/TopDownDemo.unity».
4. Нажмите кнопку Play.
